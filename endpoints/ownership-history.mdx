---
title: "Ownership History"
description: "Provenance — prior owners and title transactions for due diligence."
---

<Note>🔒 **Encrypted payload — response.** Prior-owner identities are PII → single JWE.</Note>

```http
GET /property/ownership-history/{plotID}
```

Returns the chain of ownership and title transactions for a property, used for due-diligence provenance.

## Response

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `plotID` | int | **REQUIRED** | Property key |
| `transactions[]` | Transaction[] | **REQUIRED** | Chronological history — item fields below |
| `totalCount` | int | **REQUIRED** | [Pagination](/introduction/conventions#pagination) |
| `status` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |

### `Transaction` item

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `transactionId` | string | **REQUIRED** | ADREC transaction ref |
| `transactionType` | object | **REQUIRED** | Coded value `{ constant, lookupNameEn, lookupNameAr }` — `SALE` · `GRANT` · `INHERITANCE` · `TRANSFER` · `MORTGAGE` … |
| `transactionDate` | date | **REQUIRED** | ISO-8601 |
| `fromOwnerNameEn` / `toOwnerNameEn` | string | **REQUIRED** | Parties (PII) |
| `sharePercentage` | number | **REQUIRED** | Share moved |
| `amount` | number | OPTIONAL | Consideration, if disclosed |
| `currency` | string | OPTIONAL | `AED` |

<ParamField query="pageNumber" type="integer" default="1" />
