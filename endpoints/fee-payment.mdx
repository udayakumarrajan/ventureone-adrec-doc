---
title: "Fee Payment"
description: "Pay a quoted registry fee and receive the receipt that finalises the registry write."
---

<Note>**TLS only** for the amounts and references shown here. Always **idempotent** (saga step) and **signed**. If ADREC requires payer personal identifiers, encrypt the request as a single JWE.</Note>

```http
POST /registry/fee-payment
```

Pays the fee for a pending [registry transaction](/endpoints/registry-transactions) and returns the receipt that **finalises** the registry write (checklist step 19). This is the committing step of the transfer/charge saga, so it is strictly idempotent.

<Warning>
  Send an `Idempotency-Key`. A retried payment with the same key returns the original receipt and does **not** charge twice. Pair the key with the `transactionRef` so a saga can safely resume after a timeout.
</Warning>

## Request body

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `transactionRef` | string | **REQUIRED** | The registry transaction being paid |
| `quoteId` | string | **REQUIRED** | The quote being settled |
| `paymentMethod` | enum | **REQUIRED** | `ACCOUNT_DEBIT` · `BANK_TRANSFER` · `CARD` (ADREC to confirm) |
| `paymentReference` | string | OPTIONAL | VentureOne's payment reference → `subscriptions.payment_reference` pattern |

## Response

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `receiptId` | string | **REQUIRED** | Government receipt → evidence |
| `transactionRef` | string | **REQUIRED** | Echoes the request |
| `state` | enum | **REQUIRED** | `COMPLETED` · `PENDING` · `FAILED` |
| `titleRegistrationRef` | string | CONDITIONAL | Finalised title ref, if the paid txn was a transfer |
| `paidAmount` | number | **REQUIRED** | Amount settled |
| `currency` | string | **REQUIRED** | `AED` |
| `receiptDocument` | string | OPTIONAL | Receipt PDF URL / base64 |
| `signature` | string | **REQUIRED** | JWS over the receipt |
| `status` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |

<RequestExample>
```json Request
{
  "transactionRef": "RTX-2026-0044120",
  "quoteId": "FQ-2026-771201",
  "paymentMethod": "ACCOUNT_DEBIT",
  "paymentReference": "VO-PAY-33120"
}
```

```http Headers
Idempotency-Key: vo-pay-33120-0044120
```
</RequestExample>
