---
title: "Fee Quote"
description: "Quote the government fee for a pending registry transfer, charge, or annotation before committing."
---

<Note>**TLS only.** Fee amounts and a property reference — no personal data.</Note>

```http
POST /registry/fee-quote
```

Returns the government fee for a pending registry operation so VentureOne can present and reserve it **before** committing the write. The returned `quoteId` is passed to [Fee Payment](/endpoints/fee-payment) to finalise.

## Request body

| Field | Type | Req. | Values |
| --- | --- | --- | --- |
| `plotID` | int | **REQUIRED** | Parent plot of the target property |
| `propertyId` | int | **REQUIRED** | The property being transferred / charged / annotated — the fee basis |
| `transactionType` | enum | **REQUIRED** | `TITLE_TRANSFER` · `CHARGE_REGISTRATION` · `TOKENIZATION_ANNOTATION` · `ANNOTATION_RELEASE` |
| `considerationAmount` | number | CONDITIONAL | Required for `TITLE_TRANSFER` — the transfer value |
| `chargeAmount` | number | CONDITIONAL | Required for `CHARGE_REGISTRATION` |

<Warning>
  **`propertyId` is required.** Government fees are calculated from the value of the property being transferred, so a quote for "the plot" would price the wrong asset. The quote must name the same `(plotID, propertyId)` pair as the [Registry Transaction](/endpoints/registry-transactions) that consumes its `quoteId` — ADREC should reject a mismatched pair at commit rather than charge against the wrong title.
</Warning>

## Response

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `quoteId` | string | **REQUIRED** | Pass to [Fee Payment](/endpoints/fee-payment) |
| `plotID` / `propertyId` | int | **REQUIRED** | Echoes the quoted property — verify before committing |
| `lineItems[]` | object[] | **REQUIRED** | `{ code, descriptionEn, amount }` fee breakdown |
| `totalAmount` | number | **REQUIRED** | Total fee |
| `currency` | string | **REQUIRED** | `AED` |
| `validUntil` | datetime | **REQUIRED** | Quote expiry |
| `status` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |
