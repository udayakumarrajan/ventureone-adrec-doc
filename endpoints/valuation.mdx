title: "Valuation"
description: "The official property valuation — a numeric offering input plus the certifying document."

<Note>**TLS only.** Valuation amount, valuer licence and certificate — no natural-person PII.</Note>

```http
GET /property/valuation/{plotID}
```

Returns the official valuation record for a property (checklist step 6). Kept as its own endpoint — rather than a [document](/endpoints/documents) type — because `valuationAmount` is a **required numeric input** to the offering, not just a file.

## Response

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `valuationAmount` | number | **REQUIRED** | Offering valuation input → `offerings.total_asset_value` |
| `currency` | string | **REQUIRED** | `AED` |
| `valuationDate` | date | **REQUIRED** | Certificate issue date |
| `validUntil` | date | **REQUIRED** | Certificate validity — expiry gates re-valuation |
| `valuationMethod` | object | OPTIONAL | Comparable / income / cost · coded value `{ constant, lookupNameEn, lookupNameAr }` |
| `valuerNameEn`, `valuerLicenceNumber` | string | OPTIONAL | Licensed valuer — cross-check via [Party Verification](/endpoints/party-verification) |
| `certificateDocument` | string | OPTIONAL | PDF URL or base64 |
| `status` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |
