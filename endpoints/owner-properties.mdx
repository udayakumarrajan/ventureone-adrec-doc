---
title: "Owner Properties"
description: "Resolve the properties owned by a verified identity — the entry point after issuer verification."
---

<Note>🔒 **Encrypted payload — request & response.** The Emirates ID / trade licence in the request and the owner identities in the response are PII, so both bodies are a single JWE.</Note>

```http
POST /property/owner-properties
```

Returns the properties owned by an identity — the first call after the issuer is verified. 

## Request body

| Field | Type | Req. | Values |
| --- | --- | --- | --- |
| `identifierType` | enum | **REQUIRED** | `EMIRATES_ID` · `TRADE_LICENSE` · `UNIFIED_NUMBER` |
| `identifierValue` | string | **REQUIRED** | The ID / licence number |
| `pageNumber` / `pageSize` | int | OPTIONAL | [Pagination](/introduction/conventions#pagination) |

## Response (root)

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `properties[]` | Property[] | **REQUIRED** | Owned plots — item fields below |
| `totalCount` | int | **REQUIRED** | Pagination total |
| `status` / `responseMessage` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |

### `Property` — `properties[]` item

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `plotID` | int | **REQUIRED** | Key for [Property Details](/endpoints/property-details) |
| `ownershipPercentage` | number | **REQUIRED** | Ownership-proof gate |
| `ownershipTypeNameEn` / `Ar` | string | **REQUIRED** | Ownership type |
| `eidNumber` / `licenseNumber` | string | **REQUIRED** | Match to issuer |
| `ownerNameEn` / `Ar` | string | **REQUIRED** | Owner identity |
| `plotAddress`, `districtNameEn`, `communityNameEn` | string | OPTIONAL | Pick-list display |
| `isBlocked`, `isMortgaged` | bool | OPTIONAL | Early pre-filter |
