---
title: "Owner Properties"
description: "Resolve the properties owned by a verified identity — the entry point after issuer verification."
---

<Note>🔒 **Encrypted payload — request & response.** The Emirates ID / trade licence in the request and the owner identities in the response are PII, so both bodies are a single JWE.</Note>

```http
POST /property/owner-properties
```

Returns the properties owned by an identity — the first call after the issuer is verified.

Each item is **one property**, not one plot. Where a party owns several properties on the same plot, the same `plotID` appears on several rows, each with its own `propertyId` and `ownershipPercentage`. Use the `(plotID, propertyId)` pair from the row you pick for every subsequent call — see [Identifiers](/introduction/conventions#identifiers-plot-property-owner).

## Request body

| Field | Type | Req. | Values |
| --- | --- | --- | --- |
| `identifierType` | enum | **REQUIRED** | `EMIRATES_ID` · `TRADE_LICENSE` · `UNIFIED_NUMBER` |
| `identifierValue` | string | **REQUIRED** | The ID / licence number |
| `pageNumber` / `pageSize` | int | OPTIONAL | [Pagination](/introduction/conventions#pagination) |

## Response (root)

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `properties[]` | Property[] | **REQUIRED** | Owned **properties** — one row per property, item fields below |
| `totalCount` | int | **REQUIRED** | Pagination total |
| `status` / `responseMessage` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |

### `Property` — `properties[]` item

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `plotID` | int | **REQUIRED** | The parent plot. **Repeats** across rows when the party owns several properties on it |
| `propertyId` | int | **REQUIRED** | The owned property. Pair with `plotID` for [Property Details](/endpoints/property-details) and every downstream call |
| `ownerId` | int | **REQUIRED** | This party's stake on this property — pass as `ownerId` to [Property Details](/endpoints/property-details) |
| `titleDeedNumber` | string | OPTIONAL | Deed reference for this property — disambiguates rows sharing a `plotID` |
| `unitNumber`, `buildingNumber` | string | OPTIONAL | Distinguishes properties on the same plot in a pick-list |
| `buildingNameEn` / `Ar` | string | OPTIONAL | Building name in English / Arabic — the human-readable label for a pick-list, where `buildingNumber` is only a registry code |
| `ownershipPercentage` | number | **REQUIRED** | Share **of this property**, not of the plot — ownership-proof gate |
| `ownershipTypeNameEn` / `Ar` | string | **REQUIRED** | Ownership type |
| `eidNumber` / `licenseNumber` | string | **REQUIRED** | Match to issuer |
| `ownerNameEn` / `Ar` | string | **REQUIRED** | Owner identity |
| `plotAddress`, `districtNameEn`, `communityNameEn` | string | OPTIONAL | Pick-list display |
| `isBlocked`, `isMortgaged` | bool | OPTIONAL | Early pre-filter — **per property** |

<Warning>
  `ownershipPercentage` is the share of the **property**, never of the plot. A party owning 100% of one unit on a four-unit plot is `100` here, not `25`. Reading it as a plot share would fail the ownership-proof gate for a legitimate issuer.
</Warning>

<Note>
  `totalCount` counts **properties**, so it can exceed the number of distinct plots. Paginate and display on the property row — a pick-list keyed on `plotID` alone would collapse distinct assets into one entry.
</Note>
