---
title: "Read approval requests"
description: "One approval request by id, or the requests for an offering, by state or by VentureOne's reference."
---

```http
GET /approvals/{approvalId}
GET /approvals?offeringId={offeringId}&reference={reference}&state={state}&limit={limit}
```

**Platform or officer token.** VentureOne polls `GET /approvals/{approvalId}` until an officer decides, and again while a signature is `SIGNING`. The list form lets VentureOne find a filing whose answer it lost, by its own `reference`, before filing again.

## Query parameters (list)

| Param | Type | Req. | Use |
| --- | --- | --- | --- |
| `offeringId` | string | — | One offering's requests, newest first |
| `reference` | string | — | Exact match on VentureOne's reference; requires `offeringId` |
| `state` | enum | — | `PENDING`, `APPROVED`, `REJECTED`, `SIGNING`, `SIGNED`, `SETTLED` |
| `limit` | int | — | 1–500, default 100 |

The list returns `{ approvals: [ … ] }` in the envelope.

## The approval request

| Field | Type | Use |
| --- | --- | --- |
| `approvalId` | string | ADREC's id, issued at filing |
| `approvalType` | enum | See [Approval types](/introduction/dual-token#approval-types) |
| `state` | enum | See [Request lifecycle](/introduction/dual-token#request-lifecycle) |
| `propertyRef` / `offeringId` / `offeringName` | string | As filed |
| `titleSafe` / `titleToken` | address | As filed, checksummed |
| `reference` | string | VentureOne's reference, as filed |
| `allocations[]` / `transfer` / `documents[]` | — | The payload, as filed; `units` are whole tokens |
| `decimals` | int | The Title Token's decimals, as filed and checked |
| `titleDeed` | object | The deed, as filed and checked |
| `createdAt` / `expiresAt` | datetime | An undecided request cannot be approved after `expiresAt` |
| `decidedBy` / `decidedAt` / `decisionReason` | — | The officer's decision |
| `safeTxHash` | string | The Safe transaction this approval was spent on; set from `SIGNING` |
| `signature` | string | Key 1's signature; set when `SIGNED` |
| `settlementTxHash` / `settlementBlock` / `settledAt` | — | The mined transaction ADREC checked; set when `SETTLED` |
