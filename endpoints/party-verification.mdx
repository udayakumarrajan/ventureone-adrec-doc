---
title: "Party Verification"
description: "Verify an issuer or licensed party (property manager, broker, valuer, developer) against the ADREC registry."
---

<Note>🔒 **Encrypted payload — request & response.** Carries person/entity identifiers (Emirates ID, trade licence, unified number), so both bodies are a single JWE.</Note>

```http
POST /parties/verify
```

One endpoint for every "is this party who they claim, and are they licensed / registered?" check. A `partyType` discriminator selects the party being verified — this consolidates checklist steps 2 and 20–23. It is the gate for issuer onboarding and for admitting property managers, brokers, valuers, and developers.

## Request body

| Field | Type | Req. | Values / use |
| --- | --- | --- | --- |
| `partyType` | enum | **REQUIRED** | `OWNER_ISSUER` · `PROPERTY_MANAGER` · `BROKER` · `VALUER` · `DEVELOPER` |
| `identifierType` | enum | **REQUIRED** | `EMIRATES_ID` · `TRADE_LICENSE` · `UNIFIED_NUMBER` · `LICENSE_NUMBER` |
| `identifierValue` | string | **REQUIRED** | The ID / licence number |
| `nameEn` | string | OPTIONAL | Name to cross-check against the registry record |

<Info>The platform stores an issuer's `registration_number` (nearest to a trade licence) and, for licensed parties, a `license_reference`. Send whichever `identifierType` matches what VentureOne holds for that party.</Info>

## Response

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `verified` | bool | **REQUIRED** | Registry match found and identifier valid |
| `partyType` | enum | **REQUIRED** | Echoes the request |
| `registryId` | string | **REQUIRED** | ADREC's stable key for the party — persist for later calls |
| `legalNameEn` / `legalNameAr` | string | **REQUIRED** | Registered legal name → cross-check onboarding |
| `licenseStatus` | enum | **REQUIRED** | `ACTIVE` · `EXPIRED` · `SUSPENDED` · `REVOKED` · `NOT_FOUND` |
| `licenseNumber` | string | CONDITIONAL | Required for licensed parties (PM, broker, valuer, developer) |
| `licenseExpiryDate` | date | CONDITIONAL | ISO-8601 — drives licence-expiry monitoring |
| `activities[]` | object[] | OPTIONAL | Permitted activities / scope — array of coded values `{ constant, lookupNameEn, lookupNameAr }` |
| `jurisdiction` | string | OPTIONAL | Issuing authority / emirate |
| `status` / `responseMessage` / `errorCode` | mixed | **REQUIRED** | [Envelope](/introduction/conventions#response-envelope) |

Maps to → `issuers.registration_number`, `issuers.status`, `property_managers.license_reference`, `property_managers.status`.

## Party-type cheatsheet

| `partyType` | Checklist | Typical `identifierType` | Gates |
| --- | --- | --- | --- |
| `OWNER_ISSUER` | 2 | `TRADE_LICENSE` / `EMIRATES_ID` | Issuer onboarding → portfolio lookup |
| `PROPERTY_MANAGER` | 20 | `LICENSE_NUMBER` | PM approved status |
| `BROKER` | 21 | `LICENSE_NUMBER` | Broker-introduced listings |
| `VALUER` | 22 | `LICENSE_NUMBER` | Trust the valuation source |
| `DEVELOPER` | 23 | `TRADE_LICENSE` | Off-plan / developer offerings |
