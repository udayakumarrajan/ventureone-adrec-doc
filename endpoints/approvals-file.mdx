---
title: "File an approval request"
description: "VentureOne asks ADREC to approve one Title Token movement: a batch of mints, a transfer, or document anchoring."
---

```http
POST /approvals
```

**Platform token only.** VentureOne files one request per batch of investors in one offering (see [How many requests ADREC receives](/introduction/dual-token#how-many-requests-adrec-receives)). ADREC validates the content now, so an officer never approves something that cannot be signed, and checks the title deed against its own registry. The request starts `PENDING`.

## Body

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `approvalType` | enum | **REQUIRED** | `PRIMARY_ISSUANCE`, `SECONDARY_TRANSFER` or `DOCUMENT_ANCHORING` |
| `propertyRef` | string | **REQUIRED** | The property the token represents (ADREC plot reference) |
| `offeringId` | string | **REQUIRED** | VentureOne's offering id; ADREC's record and audit trail are read per offering |
| `offeringName` | string | **REQUIRED** | Shown to the officer |
| `titleSafe` | address | **REQUIRED** | The 2-of-3 Safe that owns the Title Token |
| `titleToken` | address | **REQUIRED** | The Title Token; must differ from `titleSafe` |
| `reference` | string | Recommended | VentureOne's own reference for this filing, searchable on [Read approval requests](/endpoints/approvals-read) |
| `titleDeed` | object | **REQUIRED** | The deed exactly as [Title deed](/endpoints/title-deed) returned it: `plotId`, `propertyId`, `titleDeedNumber`, `sha256`, `anchor` |
| `allocations[]` | object[] | For `PRIMARY_ISSUANCE` | `{ wallet, units }` per investor; each wallet once, never the Safe or the token; `units > 0` |
| `transfer` | object | For `SECONDARY_TRANSFER` | `{ fromWallet, toWallet, units }` |
| `documents[]` | object[] | For `DOCUMENT_ANCHORING` | `{ name, uri, hash }`; `name` and `hash` are bytes32 hex |
| `decimals` | int | **REQUIRED** | The Title Token's decimals, 0–36 |

`units` are **whole tokens**, never base units: 50 means 50 tokens. ADREC turns them into the amounts the chain moves as `units × 10^decimals`, and checks `decimals` against the Title Token's own `decimals()` before signing. VentureOne files only whole tokens.

## Response

`201` with the [approval request](/endpoints/approvals-read#the-approval-request), `state: "PENDING"` and the `approvalId` ADREC issued. Every later call names that `approvalId`.

| Error | When |
| --- | --- |
| `1000` | A field is missing or invalid: an address, a repeated wallet, units of 0, `units × 10^decimals` beyond uint256, a payload that does not match `approvalType` |
| `1423` | `titleDeed` is not the deed ADREC's registry issues for that property |
| `1424` | No `titleDeed` was sent |
| `1403` | Called with an officer token |
