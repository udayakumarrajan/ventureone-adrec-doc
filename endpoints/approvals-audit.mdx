---
title: "Audit trail"
description: "Every step of every approval request, per request or per offering, for ADREC's own record."
---

```http
GET /approvals/{approvalId}/audit
GET /approvals/offerings/{offeringId}/audit?limit={limit}
```

**Officer token only.** ADREC's own record of every step: who did it, the state after it, and for checks, every check with its result. Oldest first. `limit` is 1–2,000 (default 500) on the offering form.

## Events

| `event` | Actor | When |
| --- | --- | --- |
| `filed` | Platform | A request was filed |
| `approved` / `rejected` | Officer | The officer's decision, with `detail` = the reason |
| `verified` | Platform | Every verifier check passed; signing requested from ADREC's custody |
| `refused` | Platform | A verifier check failed; ADREC did not sign |
| `signed` | `verifier` | Key 1's signature delivered |
| `signing_failed` / `released` | `verifier` | Signing failed; the approval is free for a corrected transaction |
| `settled` | Platform | The mined transaction passed every settlement check; units entered in the register |
| `settlement_refused` | Platform | A settlement check failed; nothing registered |

## Entry

| Field | Type | Use |
| --- | --- | --- |
| `approvalId` / `offeringId` / `offeringName` | string | Which request, which offering |
| `event` / `actor` / `state` | string | What happened, who, and the state after |
| `safeTxHash` | string | The Safe transaction involved, if any |
| `checks[]` | object[] | `{ name, passed, detail }` for `verified`, `refused`, `settled` and `settlement_refused` |
| `detail` | string | The reason, or a summary |
| `at` | datetime | When |
