---
title: "Batch Sync Beneficial Owners"
description: "Bulk-upsert the entire register for an offering so ADREC matches the cap table exactly."
---

<Note>🔒 **Encrypted payload — request & response.** Carries investor identities → single JWE. Write → send an [`Idempotency-Key`](/introduction/conventions#idempotency-writes).</Note>

```http
PUT /beneficial-owners:batchSync
```

Bulk upsert of the **entire** register for an offering — the periodic reconciliation that makes ADREC match the cap table exactly. ADREC replaces the offering's register with the supplied set.

| Field | Type | Req. | Use |
| --- | --- | --- | --- |
| `offeringReference` | string | **REQUIRED** | Register scope |
| `plotID` | int | **REQUIRED** | Property |
| `owners[]` | [BeneficialOwner](/endpoints/beneficial-owners#the-beneficialowner-object)[] | **REQUIRED** | Full authoritative set — ADREC replaces the register with this |

<RequestExample>
```http Headers
Authorization: Bearer <access-token>
Content-Type: application/json
Idempotency-Key: vo-bo-sync-2f19a7c4-9d40-4a3c-8b52-6f1e2d9c3a44
```
